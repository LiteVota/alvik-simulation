# Alvik robot model

Reusable Webots model with differential-drive wheels, simulated sensors, LEDs, and controller settings.

| File or folder | Purpose |
| --- | --- |
| [Alvik.proto](Alvik.proto) | Assembles the robot, joints, devices, collision geometry, and approximate physical parameters. |
| [meshes/alvik/](meshes/alvik/) | Body, PCB, and wheel visuals converted from Arduino's Alvik reference CAD design. |

The model assets use **CC BY-SA 4.0**. See the [source and adaptation notices](../THIRD_PARTY_NOTICES.md#arduino-alvik-reference-design) and [hardware-model notes](../docs/usage.md#hardware-model) for provenance and simulation assumptions.
